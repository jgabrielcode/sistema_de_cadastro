# sistema_de_cadastro
Projeto acadêmico de um Sistema de Cadastro Web

Projeto prático desenvolvido para a disciplina de **Desenvolvimento Web**. 

A aplicação utiliza uma arquitetura onde o Frontend (HTML/CSS/JS) envia dados de forma assíncrona para uma API em PHP, responsável exclusivamente pela transição e persistência das informações no banco de dados MySQL.

## 🛠️ Tecnologias
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
- **Backend:** PHP 8.x (PDO)
- **Banco de Dados:** MySQL
